# GREEN HARVEST

## Про проєкт

Онлайн-платформа для замовлення свіжих, органічних овочів з локальних ферм із
доставкою додому. Клієнти отримують якісні, сезонні продукти безпосередньо від
виробників, що забезпечує максимальну свіжість і користь.

## Особливості проекту

Повністю адаптивний веб-сайт з сучасним дизайном та функціоналом:

- ✅ Адаптивний дизайн для мобільних, планшетних і десктопних пристроїв
- ✅ Плавні анімації для кнопок і посилань
- ✅ Інтерактивна форма замовлення
- ✅ Responsive меню з JavaScript
- ✅ Оптимізовані зображення у форматі WebP
- ✅ Сучасний стек технологій (Vite, PostCSS)

## Технології

- HTML5
- CSS3 (з використанням сучасних можливостей)
- JavaScript (ES6+)
- Vite (збірка проекту)
- PostCSS

## Встановлення та запуск

```bash
# Встановити залежності
npm install

# Запустити dev-сервер
npm run dev

# Зібрати проект для production
npm run build

# Переглянути production збірку
npm run preview
```
